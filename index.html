Este visor permite consultar de forma interactiva la clasificación de las vías y las secciones viales normativas del distrito.

¿Cómo usar el visor?

  • Ingrese el nombre de una vía en el buscador para ubicarla rápidamente.
  • Haga clic sobre cualquier calle del mapa para ver su información.
  • Cuando corresponda, descargue la sección vial normativa disponible para cada vía.
Fuente: Municipalidad de San Borja Este visor utiliza datos públicos y no recopila información personal.

Vías Locales Preferenciales ▾
Son vías locales que, además de brindar acceso a los predios colindantes, cumplen una función de conectividad interna entre sectores urbanos y de enlace con vías colectoras o arteriales, concentrando mayores flujos de tránsito local y funcionando como rutas preferentes dentro de barrios o urbanizaciones.

Vías Locales Secundarias ▾
Son vías locales destinadas principalmente a brindar acceso directo a los predios colindantes, atendiendo desplazamientos de baja intensidad y tránsito local, sin cumplir una función relevante de conexión entre sectores urbanos. En esta clasificación de vías no se permite el transporte público.
Según nomenclatura vial:
Destinadas al tránsito vehicular
Diseñadas para el tránsito de vehículos motorizados, incluyendo accesos a viviendas y equipamientos.
Con restricción vehicular ▾
Incluyen pasajes y alamedas donde el tránsito vehicular se restringe total o parcialmente para priorizar la movilidad peatonal o la recreación.
Pasaje ▾
Vías de prioridad peatonal, con restricción física o normativa al paso vehicular permanente, salvo para residentes y emergencias.
Alameda ▾
Vías con tratamiento paisajístico predominante, que relacionan circulación pacificada con zonas de recreación pública.
